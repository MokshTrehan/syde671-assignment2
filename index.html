Part One · Filters

1.1

Convolutions from scratch

Convolution flips a kernel in both dimensions, then sums the products of overlapping samples. I implemented this operation using four loops and two loops, and applied a box filter and two derivative filters to the self portrait.

Filters
B = (1/81) · 19×9    Dx = [1, 0, −1]    Dy = DxT

Filtering the portrait

The box filter removes fine texture. The horizontal and vertical derivatives emphasize intensity changes across columns and rows. Their signed responses share a symmetric color scale. Zero padding darkens the outer rim of the smoothed image and can introduce derivative responses at the frame.

The working image is 384 × 512 pixels. Grayscale intensity is 0.299R + 0.587G + 0.114B, with RGB values in [0, 1].

Implementation

The four-loop version iterates over image rows, image columns, kernel rows, and kernel columns. The two-loop version retains the kernel loops and multiplies complete shifted image slices. Both use NumPy operations only; neither calls a convolution, FFT, window-view, or image-processing routine.

Appendices A and B contain the input checks, padding, and both complete implementations.

Finite difference operator

The cameraman image is differentiated horizontally and vertically. Gradient magnitude combines these signed responses into an unsigned measure of edge strength.

Gradient
gx = I ∗ Dx    gy = I ∗ Dy    |∇I| = √(gx2 + gy2)

Interpreting the derivatives

The horizontal response emphasizes intensity changes across columns; the vertical response emphasizes changes across rows. Convolution reverses the derivative kernel, so an increase from left to right produces a positive horizontal response.

The white border is cropped from the supplied cameraman image before resizing it to 256 × 256 pixels. Computation uses floating-point intensities in [0, 1]. The complete crop coordinates and preprocessing steps are recorded in Appendix B.

Gradient orientations

The Gaussian-derivative responses also define the direction of increasing intensity. Hue shows this direction, while brightness shows gradient strength.

Reading the orientation map

The gradient is perpendicular to an edge tangent. Image rows increase downward, so 90° points down. Weak responses are dark, and the excluded seven-pixel boundary is black.

HSV mapping
h = (θ mod 2π)/(2π)    s = 1
v = min(|∇I| / 0.2386, 1)0.7

The brightness reference, 0.2386, is the 99.5th percentile of interior gradient magnitude.

Computing the angle

The implementation uses an 18-term arithmetic series with range reduction and quadrant correction. It does not call arctangent, atan2, or an angle routine. Image sharpening

Unsharp masking adds a scaled high-frequency residual to the original image. The Gaussian blur supplies the low-frequency component; subtracting it from the input isolates detail.

Unsharp mask
B = G ∗ I    H = I − B    S = I + αH

Effect of the sharpening amount

Increasing α strengthens the Taj Mahal’s edges and texture. At the largest setting, halos and clipped highlights also become more apparent. Sharpening increases local contrast but can amplify noise and existing artifacts.

Both sharpening examples use a 13 × 13 Gaussian with σ = 2 pixels and symmetric boundaries. RGB channels are processed independently in float64. Residuals use the fixed display mapping 0.5 + 2H, so middle gray means zero.

2.1

One convolution and its limits

Expanding the unsharp-mask equation gives an equivalent single convolution. The unit impulse δ retains the original image, while the Gaussian term subtracts the blurred component.

Sharpening kernel
S = [(1 + α)δ − αG] ∗ I
K = (1 + α)δ − αG

The kernel sums to one and preserves a constant image when the boundary extension also preserves constants. Symmetric extension avoids the dark borders introduced by zero padding. At α = 1, this formulation agrees with residual addition to a maximum error of 1.78 × 10⁻¹⁵ across both examples.

Why sharpening does not undo blur

Blur then sharpen
R(f) = G(f)[1 + α − αG(f)]

The combined frequency response generally differs from one. Frequencies strongly attenuated by the blur remain attenuated after finite amplification, and clipping can remove additional information. The nonzero error map shows that stronger edges do not imply complete recovery of the original detail.

Implementation appendix

A

Convolution implementation

The shared helper validates the inputs, reverses the kernel, and pads the image with zeros. Both implementations return the same image shape and use the same padding convention.

Input validation, kernel reversal, and padding

def _convolution_inputs(image, kernel):
    image = np.asarray(image, dtype=np.float64)
    kernel = np.asarray(kernel, dtype=np.float64)
    if image.ndim != 2 or kernel.ndim != 2:
        raise ValueError('image and kernel must both be two dimensional')
    if not image.size or not kernel.size:
        raise ValueError('image and kernel must be nonempty')
    kh, kw = kernel.shape
    padded = np.pad(image, ((kh // 2, (kh - 1) // 2), (kw // 2, (kw - 1) // 2)), mode='constant')
    return (image, kernel[::-1, ::-1], padded)

Four-loop convolution

def convolve_four_loops(image, kernel):
    image, flipped, padded = _convolution_inputs(image, kernel)
    height, width = image.shape
    kh, kw = flipped.shape
    out = np.zeros_like(image)
    for y in range(height):
        for x in range(width):
            for ky in range(kh):
                for kx in range(kw):
                    out[y, x] += flipped[ky, kx] * padded[y + ky, x + kx]
    return out

Implementation appendix

B

Vectorization and image gradients

The two-loop version accumulates a complete shifted image slice for each kernel element. This changes the Python loop structure without changing the convolution sum.

Two-loop convolution

def convolve_two_loops(image, kernel):
    image, flipped, padded = _convolution_inputs(image, kernel)
    height, width = image.shape
    kh, kw = flipped.shape
    out = np.zeros_like(image)
    for ky in range(kh):
        for kx in range(kw):
            out += flipped[ky, kx] * padded[ky:ky + height, kx:kx + width]
    return out

Gradient and edge magnitude

Implementation appendix

C

Orientation without angle routines

For nonzero gradients, the ratio below lies in [0, 1]. When it exceeds √2−1, range reduction bounds the series argument by √2−1. Eighteen terms approximate arctangent; component swaps and signs recover the quadrant.

Range reduction
r = min(|gy|, |gx|) / max(|gy|, |gx|)
atan(r) = π/4 + atan((r − 1)/(r + 1))   for r > √2 − 1
atan(z) ≈ z − z3/3 + z5/5 − …

Arithmetic-only orientation implementation

def orientation_without_angles(gx, gy, terms=18):
    gx, gy = np.broadcast_arrays(np.asarray(gx, float), np.asarray(gy, float))
    if not np.all(np.isfinite(gx)) or not np.all(np.isfinite(gy)):
        raise ValueError('gradient components must be finite')
    if terms < 1:
        raise ValueError('terms must be positive')
    ax, ay = (np.abs(gx), np.abs(gy))
    high, low = (np.maximum(ax, ay), np.minimum(ax, ay))
    ratio = np.divide(low, high, out=np.zeros_like(high), where=high != 0)
    reduce = ratio > np.sqrt(2.0) - 1.0
    z = np.where(reduce, (ratio - 1.0) / (ratio + 1.0), ratio)
    z2 = z * z
    poly = np.zeros_like(z)
    for n in range(terms - 1, -1, -1):
        poly = (-1.0) ** n / (2 * n + 1) + z2 * poly
    small_angle = z * poly + np.where(reduce, np.pi / 4, 0.0)
    angle = np.where(ay > ax, np.pi / 2 - small_angle, small_angle)
    angle = np.where(gx < 0, np.pi - angle, angle)
    angle = np.where(gy < 0, -angle, angle)
    return np.where(high == 0, 0.0, angle)

A zero gradient is assigned orientation zero and displayed black. NumPy atan2 is used only as an independent validation reference.

Gaussian derivatives and sharpening

Full convolution retains the complete Gaussian-derivative support. The sharpening kernel combines the identity and Gaussian terms into one image convolution.

Build Gaussian derivative kernels

G = g1 @ g1.T
Kx = convolve2d(G, DX, mode='full')
Ky = convolve2d(G, DY, mode='full')

gy = convolve2d(image, Ky, mode='same', boundary='fill')

Single-convolution sharpening kernel

def unsharp_kernel(gaussian, alpha):
    gaussian = np.asarray(gaussian, float)
    if gaussian.ndim != 2 or any((n % 2 == 0 for n in gaussian.shape)):
        raise ValueError('Gaussian must have odd dimensions')
    if not np.isclose(gaussian.sum(), 1.0):
        raise ValueError('Gaussian must sum to one')
    kernel = -float(alpha) * gaussian.copy()
    kernel[gaussian.shape[0] // 2, gaussian.shape[1] // 2] += 1 + float(alpha)
    return kernel

The sharpening kernel is convolved with each RGB channel using “same” output and symmetric boundary extension. All intermediate arrays use float64; clipping is deferred until display export.

E

Hybrids and multiresolution stacks

The hybrid combines a low-pass source with a scaled high-pass source. The stack construction keeps every level at the original resolution; the last Gaussian level is retained as the coarse residual.

Hybrid synthesis

low = gaussian(A, sigma_low)
high = B - gaussian(B, sigma_high)
hybrid = low + gain * high

Stack construction and reconstruction

G = [I] + [gaussian(I, 2 * 2 ** i) for i in range(5)]
L = [G[i] - G[i + 1] for i in range(5)] + [G[-1]]
S = [M[i] * LA[i] + (1 - M[i]) * LB[i] for i in range(6)]
result = sum(S)

Numerical representation

Hybrid filtering uses reflected boundaries and signed float64 values. Intermediate bands are neither clipped nor contrast-normalized. Display exports clamp to [0, 1] and quantize to 8 bits; the settings table counts clipped scalar channel values. The signed high-pass display is shifted by 0.5 and includes the synthesis gain, without additional display amplification.

Spatial scale determines which structures are preserved.
